## Account Types Overview

The platform has three user roles:

1. **Admin**: Full system access, approves recruiter requests
2. **Recruiter**: Can post jobs, review applications, send emails
3. **Candidate**: Can apply to jobs, view application status

## Testing Scenarios

### Scenario 1: Candidate Workflow

1. **Login as candidate** (e.g., `john.doe@example.com`)
2. Browse available jobs
3. View job details and requirements
4. Upload resume (PDF) and apply
5. Check application status
6. View AI-generated match score
7. Track application progress

### Scenario 2: Recruiter Workflow

1. **Login as recruiter** (e.g., `sarah.wilson@techcorp.com`)
2. Create new job posting
3. View applications for posted jobs
4. Review candidate AI match scores
5. Update application status (shortlist, interview, accept, reject)
6. Generate AI-powered email drafts
7. Send acceptance/rejection emails

### Scenario 3: Admin Workflow

1. **Login as admin** (admin@airecruitment.com)
2. View all recruiter approval requests
3. Review request details
4. Approve or reject requests
5. Monitor platform activity
6. Manage user accounts

### Scenario 4: Becoming a Recruiter

1. **Login as candidate** or **create new account**
2. Navigate to "Become a Recruiter"
3. Fill out recruiter request form:
   - Company Name
   - Company Website
   - Company Email
   - Position
   - Reason for request
4. Submit request
5. **Login as admin** to approve request
6. User role changes from candidate to recruiter

## Google OAuth Testing

All accounts support both:

- **Manual Login**: Using email and password above
- **Google OAuth**: Using Google account login

To test Google OAuth:

1. Configure Google OAuth credentials (see DEPLOYMENT_GUIDE.md)
2. Click "Sign in with Google" on login page
3. First-time users will be created with role "candidate"
4. Existing users will login with their current role

## AI Features Testing

### Resume Analysis

The AI analyzes resumes and extracts:

- **Skills**: Technical and soft skills
- **Summary**: Brief candidate profile
- **Match Score**: 0-100% match with job requirements
- **Explanation**: Reasoning for the match score

### Email Generation

The AI generates professional emails for:

- **Interview Invitations**: Personalized with interview date
- **Acceptance Letters**: Congratulations and next steps
- **Rejection Letters**: Polite and empathetic feedback

## Database Seeding

To reset and recreate all test accounts:

```bash
cd ai-recruitment-backend

# Reset database (WARNING: Deletes all data)
npx prisma migrate reset

# Or manually run seed
npx ts-node prisma/seed.ts
```

This will:

- Clear all existing data
- Create all test accounts listed above
- Generate sample jobs
- Create sample applications with AI analysis

## Security Reminders

### Before Production:

1. **Delete all test accounts** or change passwords
2. **Remove or disable seed script** in production
3. **Create real admin account** with strong password
4. **Implement password complexity requirements**
5. **Add rate limiting** on login endpoints
6. **Enable email verification** for new accounts
7. **Add CAPTCHA** to prevent automated attacks
